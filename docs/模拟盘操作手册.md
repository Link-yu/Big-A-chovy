# 资金约束模拟盘 · 操作手册

> 2026-09-21 建立。规则权威见《选股框架.md》第六章与参数总表；本文只讲**怎么用**。
> 引擎：`tools/sim_account.py`｜账本：`tools/sim_data/sim_account.json`

## 一、这是什么

| | 现有「模拟仓」 | 本「资金约束模拟盘」 |
|---|---|---|
| 定位 | 信号样本采集器 | **资金曲线验证器** |
| 资金 | 不限（框架第 69/104 行原文） | **固定 10 万** |
| 考核什么 | 单个信号的 T+1 胜率 | **净值、回撤、胜率** |
| 数据载体 | `tools/shadow_data/`（影子库，本机尚未启用） | `tools/sim_data/sim_account.json` |
| 能否放行真实仓 | 否 | **否**（不参与真实仓放行） |

两者职责隔离，互不升级。本盘只验证「按框架规则机械执行，收益曲线长什么样」。

## 二、规则（已固化进 `tools/rule_config.py` 的 `sim` 段）

### 仓位口径

- 以**手**为单位，**1 手起步**——按档位算出的手数不足 1 手时按 1 手
- 单股上限 **1/4 本金 = 2.5 万**（对齐全框架真实仓单股上限）
- 单日最多新开 **5 只**
- 已持仓标的**不加仓**（框架第 17 行：绝不补仓）

| 档位 | 触发条件 | 目标金额 | 10 万下的手数示例 |
|---|---|---|---|
| **S** 起步 | 实验类别（回落放宽／合力／观察池突破／板块协同） | 固定 1 手 | 任何价位都是 100 股 |
| **A** 标准 | 正式全过（5/5 + absolute + 共振 + 分笔五档 + 基本面盈利） | 1/40 ≈ 2500 元 | 10 元票 → 2 手 |
| **B** 加强 | 正式全过 **且** 主力≥10% **且** 5分增量≥1000万 **且** 板块内候选≥2 | 1/10 ≈ 1 万元 | 10 元票 → 9 手 |

窗口修正：13:00–13:45「午后回流」手数**减半**；跨周场景目标仓位减半（框架第 114 行待验证项）。

### 买入门槛

- 正式全过，**或**框架已明确许可的模拟实验类别（逐笔标注实验类别与真实仓卡点）
- **一票否决不豁免**：公告 `avoid`/`unknown`、超大单为负

### 离场（与真实仓同标准，不放宽）

- 止损 **−3.5%**
- 止盈 **+2%**
- T+1 当日不可卖
- 次日 **09:30–09:45**，**09:45 为常规退出截止**

## 三、日常你要做什么

**什么都不用做。** 每个交易日自动跑 4 次：

| 时间 | 动作 |
|---|---|
| 09:37 | T+1 离场：逐仓判止损／止盈／09:45 截止，命中即平仓 |
| 10:07 | 早盘买入裁决（第一买点窗口） |
| 13:07 | 午后买入裁决（仓位自动减半） |
| 15:07 | 日终结算 + 净值入账 |

以上由 4 个自动化任务驱动（名称前缀「A股模拟盘·」）。它们的 prompt 里写死了「一切以脚本输出为准、不得自行决定买卖、不得用 `--force` 绕过限制」。

## 四、想看结果

```bash
python tools/sim_account.py status   # 现金 / 持仓 / 浮盈 / 净值 / 累计收益率
python tools/sim_account.py nav      # 净值曲线（按日）
python tools/sim_account.py scan     # 现在有哪些候选会被买（只读，不影响账本）
python tools/get_position.py         # 从决策记录读持仓（含模拟仓段 + 可用现金）
```

## 五、想干预

```bash
# 手动开仓（自动判档、取实时价、算股数；不在窗口内需加 --force）
python tools/sim_account.py open --code 600360

# 手动平仓
python tools/sim_account.py close --code 600360 --reason "手动平仓"

# 只看不改，不写账本
python tools/sim_account.py open --code 600360 --dry-run

# 今天不想让它自动买（在 14:20 前随时可手动）
python tools/sim_account.py auto --dry-run
```

- **暂停自动裁决**：把 4 个「A股模拟盘·」自动化任务停用即可（看板与筛选不受影响）。
- **改规则**：改 `tools/rule_config.py` 的 `sim` 段 → 同步《选股框架.md》→ 跑 `python tools/validate_consistency.py`。

## 六、文件位置

| 文件 | 说明 |
|---|---|
| `tools/sim_data/sim_account.json` | **账本（权威）**：账户、持仓、成交、净值历史 |
| `tools/sim_account.py` | 引擎：`status`/`scan`/`open`/`check-exit`/`close`/`settle`/`nav`/`sync`/`auto` |
| `决策记录/YYYYMMDD.md` | 每日同步的持仓快照 YAML + 「模拟盘成交」流水（给人读的） |
| `选股框架.md` 第六章 | 规则登记、来源、状态与权限 |

## 七、已知限制（重要）

1. **账本 JSON 是唯一权威**。决策记录里的模拟仓 YAML 由工具自动生成，手改会被下次同步覆盖。
2. **取不到实时价时按成本价估值**，净值会失真，输出里会带 `⚠️` 标记。看到标记不要据该净值下结论。
3. **不是真实下单**。成交价取触发时刻的实时价，**不模拟滑点、手续费、涨跌停无法成交、以及成交不了的情况**——所以本盘的收益曲线**天然比实盘乐观**，只能用于横向比较规则优劣，不能当真实收益预期。
4. 本机 `python3` 指向微软商店 stub，**必须用 `python`**。
5. **档位阈值是新增待验证项**（主力≥10%、5分增量≥1000万、板块内候选≥2、以及 1手起步的仓位口径）。跑满 20 个完整结算样本后再评估是否转正，**在此之前不得据此调整真实仓**。
6. 定时任务时点受调度精度影响，实际触发可能晚 1–2 分钟；`scan` 内部有 15 分钟数据新鲜度校验，超时自动空跑，不会拿陈旧快照开仓。
